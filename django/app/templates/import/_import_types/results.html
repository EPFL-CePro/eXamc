{# Requirements #}
AMC export options
  • Format: CSV
  • Sorting: line in students list
  • Include absentees: yes
  • Separator: ";"
  • Ticked boxes: "Yes: AB"
  • Columns: ID, SCIPER, NAME, SECTION, EMAIL
Question ID prefixes
  • SCQ- single choice · \begin{question}{SCQ-01}
  • MCQ- multiple choice · \begin{questionmult}{MCQ-01}
  • TF- true-false · \begin{question}{TF-01}
  • OPEN- open (optional) · \correctorFour{OPEN-A}{~}

Exam catalog PDF file Optional

The exam catalog is only used for display: it lets you preview the catalog alongside students' answers in the review view. It doesn't create questions or import any results, so you can skip it if you don't need the preview.
